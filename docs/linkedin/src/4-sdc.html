FHIR interoperability · Structured Data Capture

Two ways to submit a case. One Bundle either way.

Prohori's New Case form renders a FHIR Questionnaire generically — no field is hardcoded — then calls $extract, which hands the answers to the exact same Bundle-builder the typed API uses.

typed API
POST /cases { "disease": "dengue", "rdtResult": "positive", … } CaseBundleBuilder.Build()
=
field intake form
POST /questionnaire-response/$extract QuestionnaireResponse (rendered from Questionnaire.item[]) CaseBundleBuilder.Build()

Extraction maps answers to the same CaseSubmission the typed endpoint takes — one Bundle-shape, two ways in, so the form inherits every conformance guarantee the API already has.
