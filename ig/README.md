# ig/ — Prohori conformance profiles

FHIR Shorthand sources for the profiles the registry enforces.

```
sushi-config.yaml            SUSHI project config (FSHOnly — no IG website)
input/fsh/ProhoriPatient.fsh  the profile
input/fsh/examples.fsh        a conformant example instance
input/tests/*.json            expectation fixtures for scripts/validate-ig.sh
fsh-generated/                GENERATED by SUSHI — gitignored; regenerate before
                              validating or loading the profile
```

## Regenerate (do this first)

```bash
npm install -g fsh-sushi
cd ig && sushi . --snapshot
```

CI regenerates it in the `IG` job before validating.

## Validate

```bash
bash ../scripts/validate-ig.sh     # needs Java 11+
```

## Profiles

| Profile | Canonical | Constrains |
| :--- | :--- | :--- |
| ProhoriPatient | `https://prohori.health/fhir/StructureDefinition/prohori-patient` | `Patient` — requires a Bangladesh National ID (sliced identifier + digit invariant), `name.family`, `gender`, `birthDate` |
