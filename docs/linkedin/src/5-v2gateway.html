Most hospitals still speak HL7 v2, not FHIR. I built the bridge.

Prohori.V2Gateway parses a raw ADT feed (NHapi) and maps it onto the same Patient/Encounter Bundle shape the rest of the registry already uses — one admit, two updates, no duplicates.

Before claiming a live $transform, I checked: local HAPI advertises none for StructureMap, and the engine the spec names couldn't be reached. So the FHIR Mapping Language is authored and documented, not faked as running — the honest answer beat the impressive-looking one.
